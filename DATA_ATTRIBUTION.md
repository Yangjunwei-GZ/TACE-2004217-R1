# Data attribution and scope

The de-identified numerical inputs derive from WAW-TACE by Krzysztof Bartnik and colleagues, version 2, DOI 10.5281/zenodo.12741586. The repository metadata identifies the data licence as Creative Commons Attribution 4.0 International (https://creativecommons.org/licenses/by/4.0/). Its technical information also describes scientific research use. Cite the source data and source publication, DOI 10.1148/ryai.240296, and comply with the source terms. This data notice is separate from the MIT licence of the analysis software.

This candidate contains derived clinical/features tables using the public source identifiers. No original CT, source images, patient names, doctor review forms or signatures are included. Original images and masks must be obtained from https://zenodo.org/records/12741586. Local absolute image paths have been replaced by portable source-data placeholders. The resulting CSV byte hashes differ from the exact local run; numerical cells and public identifiers are checked unchanged by the distribution audit. No old checkpoint is relabelled or given a new hash. The original 510 actual-run checkpoints and their original input bindings are retained, without rewriting, in the separate exact local reproduction archive.
